## How the site is built
- Netlify runs `node build.js` (Node 20) and publishes `dist/`. `netlify.toml` only sets the command and folder.
- `components/` (head, nav, modal, footer) are injected into every page at build time — **don't paste them into pages.**
- `pages/*.html` hold only page-specific head tags, `<style>`, body content and scripts. `pages/Index.html` (capital I) is the homepage.
- City pages (`{slug}-cashback-realtor.html`) come from `templates/city-template.html` + `data/cities.json`; neighbourhood pages from `templates/neighbourhood-template.html` + `data/neighbourhoods.json`. Optional per-city fields: `h1`, `h1Tagline`, `localFacts`.
- `assets/shared.js` is inlined at the end of every page (modal, form submit to Netlify Forms + HubSpot, GA4 events, A/B test, breadcrumbs).
- **Form field names in `components/modal.html` must match `NETLIFY_FORM` in `build.js`**, or Netlify silently drops those values. Consent wording must match HubSpot's form text and the constants in `shared.js`.
- `dist/sitemap.xml` is generated by `build.js` from the real pages (noindex pages excluded). The root `sitemap.xml` is only a seed that keeps existing lastmod/priority values.
- Share image: `design/og-image.html` → `og-image.png` (render with `node scripts/render-og-image.js`).
- Repeated guide-page styles live in `assets/guide-pillar.css` and `assets/guide-pillar-alt.css`.

## Tests
- One-time: `cd tests && npm install && npx playwright install chromium`
- Run from the repo root: `npm test`. It builds the site, serves `dist/`, and checks every page at 390px (script errors, missing files, sideways scrolling, one H1, pop-up opens), plus sitemap, share image, each feature, the form payloads (Netlify + HubSpot), the A/B test, and pop-up accessibility. Must end with `0 failed`.
- `tests/known-issues.json` lists problems that already existed; fix them and delete the entry.
- `tests/` has its own package.json so Netlify never installs Playwright.
